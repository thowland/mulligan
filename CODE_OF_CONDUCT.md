# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short, everyone taking part in issues, pull requests and discussions is expected to be respectful and constructive, and harassment of any kind is not tolerated.

Problems can be reported to th@wdogsystems.com. Reports are handled in confidence, and the maintainer may remove, edit or reject contributions, or block participants, who do not follow the code.
